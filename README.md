# conduces-qr

Página pública del **código QR** de los conduces del Sistema de Conduces (Grupo Económico Torres Rodríguez).

**No contiene datos.** Al escanear el QR, esta página busca la dirección actual de la oficina, comprueba que esté
firmada por la oficina y lleva al conduce (solo para verlo). Si la oficina está apagada, lo avisa.

- Lo que viene en el QR va después de `#`: el navegador no lo envía a GitHub.
- La fuente está en el repositorio privado del sistema (`pagina-qr/index.html`). Si se cambia allá, se copia aquí.
